Endpoints

Verify each message

Every request carries two headers. Check the signature with your endpoint's signing secret before you trust the body, and ignore event ids you have already handled.

Aerrand-Event-Id: evt_… Aerrand-Signature: t=<unix time>,v1=<hex> v1 = HMAC_SHA256(secret, t + "." + raw_body)

Reject a message when the timestamp is more than 5 minutes old. If your server is down we retry up to five more times with growing waits.
